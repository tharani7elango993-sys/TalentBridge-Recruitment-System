# TalentBridge – Recruitment Management System

## 📌 Project Overview
TalentBridge is a Full Stack Recruitment Management System designed to simplify and manage the recruitment process. It provides a platform for job seekers, recruiters, and administrators to manage job opportunities and recruitment activities efficiently.

## 🎯 Objectives
- Simplify the recruitment process.
- Manage job postings and applications.
- Provide secure user authentication.
- Help recruiters manage job seekers.
- Generate recruitment-related reports.

## ✨ Key Features
- User Authentication and Login
- Job Management
- Job Seeker Management
- HR / Recruiter Management
- Recruitment Report Generation
- Frontend and Backend Integration
- Database Management

## 🛠️ Technologies Used

**Frontend**

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/tharani7elango993-sys/TalentBridge-Recruitment-System.git
```

2. Open the project folder:

```bash
cd TalentBridge-Recruitment-System
```

3. Install backend dependencies:

```bash
cd backend
npm install
```

4. Install frontend dependencies:

```bash
cd ../frontend
npm install
```

5. Configure your MongoDB connection and environment variables.

6. Start the backend and frontend using the scripts specified in their respective package.json files.
